O que este site é
Este site é uma plataforma simples para quem quer criar um currículo profissional.

O que ele faz
Mostra exemplos de currículos prontos
Apresenta diferentes modelos: profissional, criativo, de estágio, full stack, marketing, UX/UI etc.
Ajuda a entender como estruturar texto, habilidades e destaques no currículo

O que dá para fazer nele
Ver currículos prontos e exemplos inspiradores
Buscar por tipo de currículo, cargo ou profissão
Escolher um modelo e usar como base para criar seu próprio currículo
Navegar pela seção “O que oferecemos” para entender os tipos de modelo disponíveis
